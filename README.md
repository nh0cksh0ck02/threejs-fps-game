High-performance Three.js Tactical FPS with dynamic lighting, responsive recoil, particle physics, and target dummies.

## Gameplay Controls

- **WASD**: Tactical movement (strafe, forward, back)
- **Space**: Jump over low obstacles
- **C / Ctrl**: Crouch for improved recoil stability and tighter weapon spread
- **Left Click**: Fire semi-automatic / burst hitscan rounds
- **R**: Tactical magazine reload
- **Mouse**: 360-degree pitch and yaw freelook

## Run it

```sh
node serve.ts
```
